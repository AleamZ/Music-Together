# v18.11 Báo Làng — plan

Spec: `docs/superpowers/specs/2026-09-27-v18-design.md` §18.11 (+ owner addition: 24 h dev-blog popup).

## Server — `supabase/migrations/0032_news.sql`
1. Tables: `news_posts` (global: title, emoji, body, pinned, created_at, updated_at, author), `news_events` (room-scoped,
   kind/text/meta, trimmed to 300 per room on insert), `news_post_reads` (account → last_post_seen_at),
   `news_event_reads` (account, room → last_event_seen_at). RLS on, no policies.
2. `_news_event(room, kind, text, meta)` (internal, revoked) + `_news_home_room(account)` (most recently seen room).
3. Hooks without re-creating functions another agent is editing:
   - legendary catch: AFTER INSERT trigger on `chat_messages` for the `[catch:acct|species|g]` system line, rarity 5
     (survives 0031's new `finish_cast`);
   - anti-cheat ban: AFTER UPDATE trigger on `anticheat_status` (ban_state null → pending_wipe), room = the strike's room;
   - car: AFTER INSERT trigger on `owned_vehicles` (vehicle `car`), room = home room;
   - big card win: `_card_settle` re-created (only defined in 0017) — net = escrow − the hand's `card_hold`,
     logged when net ≥ 20 × stake and ≥ 500 xu.
   - Seam comment: lightning, drown/rescue, overboard, house purchase call `_news_event` later.
4. RPCs: `news_feed(room, token)` (pinned+recent posts, 50 recent events, unread counts, `popup` = posts of the last
   24 h newer than the viewer's post marker, oldest first), `news_mark_read(room, token, kind)`,
   `news_admin_list`, `news_post_upsert`, `news_post_delete` (root via `_auth_root`).
5. `tests/sql/v18-11-smoke.sql`; replay on a throwaway PG18 (port 54334).

## Client

- Hall prop + interactable `news_stand` ("Báo Làng"), original pixel-art kiosk; hall exact-ids tests updated.

- GameShell `case "news_stand"` before default; pinned-cases test updated.
- Admin tab "Bản tin": create / edit / pin / delete.
