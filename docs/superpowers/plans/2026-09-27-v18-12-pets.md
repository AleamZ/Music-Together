# v18.12 Thú cưng Implementation Plan

> **For agentic workers:** Steps use checkbox (`- [ ]`) syntax. TDD: write the test, see it fail, implement, see it pass.

**Goal:** a pet shop at Chợ Lớn; six species with colour variants; one active pet follows its owner on every map and is seen by everyone; care (no/vui) decays on the server; food, toys, per-species fashion; small per-species buffs.

**Spec:** `docs/superpowers/specs/2026-09-27-v18-design.md` §18.12.

**Architecture:**
- **Catalog + rules** (`lib/game/pets/catalog.ts`, `lib/game/pets/model.ts`): species, variants, prices, items, rates, sulk rule, buff table, name sanitiser, the `pt` code (encode/parse). Mirrored by `0036_pets.sql`; `tests/unit/pets.test.ts` pins the SQL catalog rows and rates equal to the TS ones.
- **Server** (`supabase/migrations/0036_pets.sql`): `pet_item_catalog`, `pets`, `pet_items`, `pet_owner`; helpers `_pet_species_price`, `_pet_variant_ok`, `_pet_name`, `_pet_now` (lazy decay), `_pet_json`, `_pets_state`; RPCs `pets_state`, `pet_buy`, `pet_buy_item`, `pet_feed`, `pet_play`, `pet_set_active`, `pet_rename`, `pet_equip`, `pet_tick` (sóc forage); `_vitals_apply(uuid, numeric, numeric)` (hunger factor) and `vitals_tick` re-created from 0033 with the mèo factor; the ledger check re-created with the 28 reasons of 0034 + `pet_buy`, `pet_find`.
- **Net** (`lib/game/net/protocol.ts`): optional `pt` on st/mv/pa (validated by `parsePetCode`; bad → dropped).
- **Follow** (`lib/game/pets/follow.ts`): `PetFollowers` — per owner a breadcrumb trail, the pet walks to the point 14 px behind; hidden while riding/swimming; snaps after a teleport. Pure (unit-tested).
- **Art** (`lib/game/art/pets.ts`): 16×16 frames per species × facing (down/up/right; left mirrors) × 3 poses (walk cycle 1-0-2-0), palettes per variant, fashion overlays per slot anchored per species. `lib/game/art/pet-shop.ts`: the kiosk (back + counter sprites) for market-art.
- **Engine** (additive): `setPet(code, speed)`, `pt` on my movement messages, remote codes from messages, `PetFollowers` stepped in update and drawn depth-sorted; parrot echo bubble.
- **UI**: `lib/game/pets/rpc.ts`, `hooks/usePets.ts` (state + 60 s `pet_tick`), `components/game/PetShopModal.tsx`; GameShell: `case "pet_shop"` → `setPanel("pet_shop")`, `setPet` effect, sóc toast; `SHELL_PANEL_OF.pet_shop`.
- **Map**: `PET_SHOP_FRONT` kiosk at (700, 212, 64×32) solid; interactable `pet_shop` used from (732, 264) facing up; NPC cô Mười (look in `lib/game/pets/npc.ts`); city-map places list.
