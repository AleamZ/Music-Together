# v18.13 Đi nhờ xe — implementation plan

Spec: `docs/superpowers/specs/2026-09-27-v18-design.md` §18.13. Client only, no migration. TDD per task.

1. **Protocol** (`lib/game/net/protocol.ts`, `budget.ts`): `p`/`lf` on st/mv/pa (ids, validated); new events `rq {to}`,
   `ra {to, ok, v?}`, `rx {to}`, `lg {to, m}` in GAME_EVENTS; budget kind `lift` (1/s, burst 4). Tests: parse, budget.
2. **Lift model** (`lib/game/travel/lift.ts`, pure): `LIFT_RANGE`, `LIFT_ASK_MS`, `LIFT_SYNC_MS`, `LIFT_LOST_MS`;
   `liftReduce(state, event)` → `{ state, send[], toast?, follow? }` for ask / rq / accept / decline / ra / rx / leave /
   drop / dismounted / lost / lg / tick; `dropSpot(blocked, pos, facing)`. Tests.
3. **World** (`lib/game/world.ts`): remember `p`/`lf`; `carrier(id)` / `passengerOf(id)` only when both agree;
   `liftOf(id)`; the carried actor is pinned to its driver in `tick`; `pin(id, …)` for my own passenger. Tests.
4. **Engine** (`lib/game/engine.ts`, additive): `setLift`, `liftProbe`, `p`/`lf` on my moves; the passenger follows the
   driver's actor, input/taps/prompts off; drawing: pillion on the driver, the carried actor not drawn alone; lost-lift
   checks → `onLiftLost`; `dropSpot` when a passenger's lift ends.
5. **Art** (`lib/game/art/ride.ts`, `road.ts`): `drawRide(..., pillion?)` for the 3 vehicles × 4 facings;
   `drawTraveller(..., pillion?)` for the road. Pixel tests + preview `passenger.png`.
6. **Canvas** (`GameCanvas.tsx`): keeps the lift across worlds (set after `setRiding`, after the channel exists),
   forwards rq/ra/rx/lg to the shell, `sendLift`, `liftProbe`; regression test through a portal.
7. **Shell** (`hooks/useLift.ts`, `components/game/LiftHud.tsx`, small `GameShell.tsx` additions): the buttons, E key,
   driver prompt, expiries, drop on dismount/faint, `lg` before a portal, following the driver (portal or road trip),
   `RoadTripOverlay` with the pillion and no skip for the passenger. Tests.
8. Verify: vitest, tsc, eslint on touched files; report.
