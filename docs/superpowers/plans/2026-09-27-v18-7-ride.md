# v18.7 Lái xe trong map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**
- **Mount and dismount.** A player who owns a vehicle (v18.5) can get on it and ride around any map: HUD button "🚲 Lên xe" / "Xuống xe", key **R**. Owners of more than one vehicle pick which one.
- **Speed.** Riding multiplies walk speed: bike ×1.6, moto ×2.2, car ×2.8.
- **While riding** the player cannot interact with anything: no fishing, farming, seats, shops or NPCs. Portals still work, and the hall↔market trip uses the ridden vehicle.
- **Visibility.** Other players see the vehicle.
- **Car at the pond.** The car cannot be ridden on the pond map: mounting it there is refused, and entering the pond while in the car dismounts the player.
- **Starving.** A player at 0 hunger or thirst is dismounted.

**Architecture:**
- Pure rules live in `lib/game/travel/ride.ts`: the speed factors, `canRide(map, vehicle)`, and the interaction gate.
- The engine gains a `riding: VehicleId | null` state. Its effective speed is `WALK_SPEED × starving factor × ride factor`.
- The presence state message gains an optional field `v` (the vehicle id), like the fishing phase `f`.
- `lib/game/art/ride.ts` draws the vehicle and the seated rider for the 4 facings in world pixels, reusing the seated-rider technique from `lib/game/art/road.ts` (`seatedRider`).
- GameShell adds the HUD button, the R key, the vehicle picker, and the gates.

**Tech Stack:** Next.js 16 (read `node_modules/next/dist/docs` before framework APIs), React 19 + React Compiler lint, TS strict, Vitest 4 (`cleanup()` in `afterEach`), pnpm.

**Spec:** approved in chat on 2026-09-27 (the answer was "A"); the goal above is the spec. It depends on v18.5 (`lib/game/travel/vehicles.ts`, `hooks/useVehicles.ts`, the road trip) and v18.3 (vitals, `speedFactor`).

```ts
import type { InteractKind, MapId } from "@/lib/game/maps/types";
import type { VehicleId } from "@/lib/game/travel/vehicles";

// v18.7: riding a vehicle around the maps. Cosmetic + faster walking; no interactions but portals while riding.

export const RIDE_SPEED: Record<VehicleId, number> = { bike: 1.6, moto: 2.2, car: 2.8 };
export const RIDE_KEY = "r";

export const canRide = (map: MapId, v: VehicleId): boolean => !(map === "pond" && v === "car");
export const rideSpeed = (v: VehicleId | null): number => (v ? RIDE_SPEED[v] : 1);
export const interactBlocked = (riding: VehicleId | null, kind: InteractKind): boolean => riding !== null && kind !== "portal";
```
