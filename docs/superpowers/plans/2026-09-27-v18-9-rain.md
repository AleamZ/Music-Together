# v18.9 Ô và ướt sũng + sét đánh — plan

Spec: `docs/superpowers/specs/2026-09-27-v18-design.md` §18.9 (and the lightning addendum under §18.10). Owner chose
option C: wet → (5 min) fast hunger → hunger 0 → cảm lạnh; still wet 5 more min while cảm lạnh → ngất. Lightning 1 %/min
outdoors in rain/thunder/storm (an umbrella does not protect), the v18.3 faint flow (wake in the hall), 30 min cooldown.

| Lightning | outdoors in a rainy room, not in cooldown: P = 1 − 0.99^(dt/60) per heartbeat (dt = credited s, ≤ 120); hit → faint, `strike_cd_until = now + 30 min` |
